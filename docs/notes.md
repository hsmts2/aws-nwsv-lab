# Notes

このドキュメントでは、`aws-nwsv-lab` の補足メモを整理します。

## 学習観点

- VPC 内にパブリックサブネットとプライベートサブネットを作成する
- Internet Gateway と NAT Gateway の役割を分けて理解する
- Web サーバーと DB サーバーを分離した2層構成を作成する
- Security Group により通信元と通信先を制限する
- 手動構築した内容を CloudFormation テンプレートとして再現する

## 設計メモ

- このリポジトリは基礎学習用のため、構成は Web サーバー + DB サーバーの最小構成に絞っています。
- DB は書籍の学習構成に合わせて EC2 上の MariaDB として構築します。
- 実環境用パラメータファイルには IP アドレスやキーペア名が含まれるため、Git 管理対象外にします。

## 今後確認したいこと

- CloudFormation の `validate-template` と `cfn-lint` による構文チェック
- Web サーバーへの HTTP アクセス確認
- Web サーバーから DB サーバーへの 3306/TCP 疎通確認
- スタック削除後に課金対象リソースが残っていないことの確認
